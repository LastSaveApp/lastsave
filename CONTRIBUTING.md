# Contributing to LastSave

Thanks for wanting to help 💙 LastSave is built by one developer with a small group of players, and
every report, idea and translation shapes what comes next.

**The application's source is not public**, so this repository does not take code. It holds the
releases, the issues and everything the community can change directly: today, the translations.

## Report a bug

The fastest way is from inside the app: **Settings → About → Report a bug or send feedback**. It
attaches your app version, Windows version and the log for you. You can also
[open a bug report](https://github.com/LastSaveApp/lastsave/issues/new?template=bug_report.yml)
here. Issues are public, so leave out anything private.

A security problem is never a public issue: [here is how to report it privately](https://github.com/LastSaveApp/.github/blob/main/SECURITY.md).

## Suggest an idea

[Open an idea or request](https://github.com/LastSaveApp/lastsave/issues/new?template=feature_request.yml),
start a thread in [Discussions](https://github.com/LastSaveApp/lastsave/discussions), or talk it
through on [Discord](https://discord.gg/cgTuQXwvA4), where most of it happens.

## Translate LastSave

Every language lives in [`translations/`](translations/), MIT-licensed, and pull requests are
welcome there. The [translation guide](translations/README.md) has the rules, the files and two
ways in: the **Language Studio** inside LastSave (no Git needed) or a pull request from your fork.
Everyone who translates is named in [the credits](translations/CREDITS.md) and in the app.

## Pull requests

- **Welcome:** changes to `translations/<language>/`. A check runs on every one, and the team (or
  the language's maintainer) reviews it before it is merged.
- **Not taken:** changes to the English in `translations/en/` or to `translations/tools/`, which are
  copied from the app and would be overwritten. If the English is wrong, open a
  [translation issue](https://github.com/LastSaveApp/lastsave/issues/new?template=translation.yml).
- Anything outside `translations/` is the team's: open an issue first.

## Spread the word

A ⭐ on this repository, a post about the games you finished, or LastSave shared with a friend
helps other players find it.
